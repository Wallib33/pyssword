# Pyssword

Pyssword is a python password generator that is been made for me. The idea is made a simple project for ptraticing the basics of python and my english.

# Objectives

The goal is make a simple password generator with:

- Generators mode (PIN, Alphanumeric, Complex and Custom mode).

- A TUI simple menu.

- Repetitive structure of script.


# Future Objectives

I have plans to storage the password generated and integrate with Json or other password manager(Bitwarden, ProtonPass, KeePassXC and more...). Using a [Have I Benn PwneD](https://haveibeenpwned.com/) API that validade the security of the password and show to you.
